# Sample data

**Everything here is made up.** The companies, people, addresses and numbers are fictional. Never add real invoices, receipts, or personal data.

| Folder | What | Used from |
|---|---|---|
| `invoices/` | Business invoices (B2B, line items, tax, due dates) | Module 01 |
| `receipts/` | Shop and restaurant receipts (short, messy, tips) | Module 01 |
| `golden/` | Hand-checked correct answers for evals | Module 02 → 09 |

Module 01 uses plain-text documents, so we learn LLM calls without file parsing getting in the way. PDFs and phone photos come in Module 02.

Public receipt datasets (SROIE, CORD) are added in later modules, with their licenses noted.
