SECTION 3

Keys and accounts

Explain like I'm 10

An API key is a password that also works as a credit card. Whoever holds it can spend your money. So we keep keys in one locked drawer (.env), never in the code, and hand the app only a pocket-money card (Module 01).

What to create

Name in .envWhere it comes fromWho reads it
ANTHROPIC_API_KEYconsole.anthropic.com → API keysGateway only
OPENAI_API_KEYplatform.openai.com → API keysGateway only
LITELLM_MASTER_KEYYou invent it (see below); must start with sk-Gateway + admin lessons
DATABASE_URLA free hosted Postgres, for example neon.tech → new project → connection stringGateway only
DOCUMIND_API_KEYIssued by the gateway in Module 01, lesson L04DocuMind
cp .env.example .env                    # then fill in each value
python3 -c "import secrets; print('sk-admin-' + secrets.token_urlsafe(24))"   # a master key

Why Postgres before any AI code? The gateway stores its virtual keys, budgets and spend in a database. Later modules keep documents and vectors there too. A hosted one works the same from your Mac and from Colab. Free tiers change, so check the current terms when you sign up.

Spending. Module 01 costs a few cents. Set a monthly limit in both vendor consoles as well; the gateway budget in Module 01 is a second fence, not the only one.

In Colab, use the key icon in the left sidebar (Colab Secrets) instead of .env, with the same names.

Code alonglessons/L02_check_env_file.pypython3 modules/00-course-setup/lessons/L02_check_env_file.py # checks names only; never prints a value
At enterprise scale
  • No personal API keys for company work. Use the organization's approved vendor accounts, which carry the right data-processing and retention terms.
  • Secrets come from a secrets manager, not a file on a laptop. A .env file is a development convenience only.
  • A key that has ever been committed to git is leaked. Revoke it and issue a new one; deleting the commit is not enough.
SECTION 4

The documents

DocuMind learns on made-up documents in data/. Every company, address and number in them is fictional, and every total adds up, so later modules can check the maths.

FileWhat makes it interesting
invoices/INV-1001-acme-supplies.txtClean US invoice: line items, 8% tax, net-30 terms
invoices/INV-2047-globex-cloud.txtGerman supplier: euros, 19% VAT, two languages
receipts/RCPT-3001-bean-there-cafe.txtCafé receipt: a tip, a card payment
receipts/RCPT-3002-handy-hardware.txtShop receipt: quantities, a discount, cash and change

Notice how differently they are laid out. A fixed template can't read all four; a model can. That variety is the reason to use an LLM here. Module 01 uses plain text; PDFs and phone photos arrive in Module 02.

CHECKPOINT

Ready for Module 01?

Why does .env exist, and why is it in .gitignore?

It keeps secrets out of code and out of git. A pushed key counts as leaked.

Which program reads ANTHROPIC_API_KEY and OPENAI_API_KEY?

Only the LiteLLM gateway. DocuMind itself never sees them.

Why do we need Postgres before writing AI code?

The gateway keeps virtual keys, budgets and spend in it.
